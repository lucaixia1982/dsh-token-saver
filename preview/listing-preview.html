dsh-token-saver

@acmepoyen · MIT · DeepSeek Harness 0.2.x
GitHub 仓库npm 包讨论

它是一个「先瘦身、再记账、后展示」的三段式插件：

瘦身只删无语义损失的字符：行尾空格、连续空格、连续空行、重复行、重复段落、结尾寒暄。代码块不动，运行时上下文不动，收益 <15 token 或 <4% 时保留原文。
记账每次调用记录未命中输入、命中输入、输出；修正 DeepSeek inputTokens 只含未命中部分的口径。
展示左侧栏徽章：本次 ¥X · 累计 ¥Y；悬停八行明细，含命中率与缓存前缀重建次数。
隐私全部本地：聚合数据写到 ~/.dsh/dsh-token-saver.json，不联网、不上报。
