## 每张图的建议配文

**fig0-cover**：题图。文案建议直接写「给 AI 装个省钱表：指令先瘦身，再把缓存差价算成钱」。

**fig1-mechanism**：三段式 —— 你打的字 → 瘦身器 → 进模型的指令；下半张是记账口径（未命中 ¥2 / 命中 ¥0.2 / 输出 ¥3 每百万 token）和左侧栏徽章。这张解释「为什么能省钱要分两步看」。

**fig2-slimming**：同一条指令，左 188 tok、右 124 tok。红的都是删掉的：一个重复段落、一句「谢谢！」、一个空行。代码块完全不动。

**fig5-badge.gif**：徽章从 ¥0 涨到「本次 ¥2.39 · 累计 ¥34.00」，右边明细和两根对比条同步长。这个 GIF 就是回答你「省钱变化」的那张。

**fig3-cost**：同样 225 次调用，「全部未命中 ¥38.98」对比「实付 ¥4.98」，差 ¥34.00。这是最该放大的那张 —— 真正省钱的是缓存差价，不是压缩提示词。

**fig4-install**：三步 + `cordis.patch.yml` 那三行 + 兼容性。

## 数字口径（写文章时别写错）

本机实测，截至 2026-11-09：

- 调用 225 次；输入 10.60M token，其中命中 10.35M，命中率 97.8%
- 实付 ¥4.98；若全部按未命中价 ¥38.98；差额 ¥34.00（插件口径「累计省」）
- 指令瘦身：只有 1 条触发，省 64 token，约 ¥0.0001 —— 是零头
- 价格默认：未命中 ¥2 / 命中 ¥0.2 / 输出 ¥3，每百万 token，可在 config 改

## 三句别写出口的话

1. 别写「插件提高缓存命中率」。DSH 本身就保持提示词前缀稳定，命中率来自它；插件只做两件事：把自然语言指令瘦身、把命中与未命中的差价算成钱。
2. 别写「压缩提示词能省一半」。实测省的是 34%，换算成钱只有万分之一量级。
3. 别写「所有模型都适用」。默认价码按 DeepSeek 目录价写的，换网关要自己改三个价格。
